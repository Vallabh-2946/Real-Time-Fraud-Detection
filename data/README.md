
# Dataset Instructions

## Dataset Name
Credit Card Fraud Detection

## Source
[Kaggle - Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Download Instructions

1. Open the Kaggle dataset link.
2. Download the dataset.
3. Extract the downloaded ZIP file.
4. Copy `creditcard.csv` into this folder.

## Expected File Location

```text
Real-Time-Fraud-Detection/
└── data/
    ├── README.md
    └── creditcard.csv
```

**Note:** The original CSV file is excluded from GitHub because it is approximately 150 MB. Download it separately before running the analysis scripts.
